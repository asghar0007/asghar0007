I am a seasoned **DevOps & Cloud Engineer** with **8+ years of experience** designing, building, and automating robust infrastructure, continuous integration/deployment (CI/CD) pipelines, and containerized environments. I specialize in bridging the gap between development and operations to deliver scalable, secure, and highly resilient cloud solutions.

### 🚀 What I Do
- **Cloud Architecture & Migration:** Designing highly resilient, secure cloud infrastructures (AWS, Azure, GCP).
- **Infrastructure as Code (IaC):** Automating environment provisioning and configuration using Terraform, Ansible, and CloudFormation.
- **Containerization & Orchestration:** Building, deploying, and scaling microservices with Kubernetes (EKS, AKS, GKE) and Docker.
- **CI/CD Automation:** Architecting reliable delivery pipelines using GitHub Actions, GitLab CI, Jenkins, and ArgoCD.
- **Observability & Monitoring:** Implementing proactive alerting and monitoring dashboards using Prometheus, Grafana, and ELK stack.
